INSTALAR AS DEPENDENCIAS DO REACT-NATIVE E EXPO PARA EXECUTAR:

	1. cd cleartech

	2. npm install

	3. npx expo start -c

	4. apontar câmera do celular com SDK54 do expo go (se não tiver, abaixe no site oficial)

INICIAR O BANCO DE DADOS É NECESSÁRIO MUDAR ALGUMAS INFORMAÇÕES:

	1. cd cleartech
	2. cd .env
	3. mude o endereço de ip para o da sua maquina atual
	4. cd src
	5. cd services
	6. cd config.ts
	7. mude o endereço ip para o da sua maquina

SE QUISER ACESSAR O SISTEMA DOS FUNCIONARIOS DE GERAÇÃO DE QR-CODES DE COLETA:

	1. cd ct-funcionarios
	2. node server.js

EXECUTAR O BANCO DE DADOS:

	1. cd backend
	2. cd src
	3. node server.js


OBS::QUANDO QUISER USAR OS 3 SISTEMAS AO MESMO TEMPO DEVERÁ SER DEIXADO 3 TERMINAIS ABERTOS E EXECUTADOS COM OS PROPOSTOS PROGRAMAS
	 ALÉM DISSO EXECUTAR NAS 3 PASTAS 'npm init -y' PORFAVOR
